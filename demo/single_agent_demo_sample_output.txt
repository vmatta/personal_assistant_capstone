REJECTED CANDIDATES (tested, not reliable enough for a live demo):

1. "List all my tasks for this week" (as a scheduler_todo demo)
   -> Occasionally misroutes to notes_knowledge instead of scheduler_todo due to the
      word "list" alone not being a strong enough routing signal. Use "Show me all my
      scheduled events for today" instead, which reliably routes to scheduler_todo.

2. "What is my favorite color?" run on a FRESH/unrelated thread (as a notes_knowledge demo)
   -> The vector store persists across the whole process/session, so a fresh thread's
      query can retrieve a stale note saved by an EARLIER unrelated test run in the same
      session, which then confuses the QA critic (it scored this 0.0 - "unsupported
      assumption" - because it has no visibility into retrieval evidence, only the final
      text). Always chain a "save" + "query" pair on the SAME thread_id for a demo.
